# 남강유향 게임 프로젝트

## 목적

남강유향을 지역 방문객에게만 판매되는 단발성 관광상품이 아니라, 온라인에서도 계속 발견되고 기억되는 브랜드 경험으로 확장하는 짧은 게임 프로젝트다.

관광상품은 지역을 실제로 방문한 사람에게만 판매 기회가 생기며, 방문 뒤에는 관계와 구매가 끊기기 쉽다. 이 게임은 남강유등의 “안부를 전하는 빛”이라는 의미를 온라인에서 플레이 가능한 이야기로 전달해, 지역 밖의 사람도 남강유향을 발견하고 기억하게 만든다. 게임을 마친 플레이어는 선택적으로 온라인 마켓과 제품·콘텐츠를 만난다.

게임은 명확한 브랜드 마케팅 콘텐츠이지만, 배너·쿠폰·강제 전환 도구가 아니다. 플레이 자체가 재미와 결말을 갖고, 제품 구매는 게임의 승패·진행도·확률·보상에 영향을 주지 않는다.

## 첫 번째 게임: 5분 프롤로그

- 가칭: **《남강의 불빛: 안부를 띄우는 밤》**
- 형식: 모바일 브라우저에서 바로 실행되는 도트 그래픽 게임
- 목표 플레이 시간: 약 5분, 로그인·설치·권한 요청 없음
- 장르: 짧은 유등 배치 디펜스
- 플레이어 역할: 남강을 지키며 사라지는 안부를 유등으로 되돌리는 등지기

### 핵심 루프

`유등 배치 → 침입 파도 방어 → 적 저지로 향 게이지 충전 → 원하는 순간 향 피우기 → 모든 유등의 광역 점등 → 안부의 등불 띄우기`

향은 실제 제품의 효능을 말하는 장치가 아니라 게임 안의 창작 규칙이다. 게이지가 찼을 때 플레이어가 수동 발동하면, 짧은 시간 동안 모든 유등이 강화되고 화면을 환하게 덮는 광역 점등이 일어난다.

## 세계관과 표현 원칙

진주성 방어전과 유등의 안부 서사에서 출발하되, 인물·사건·침입군·향의 힘·게임 규칙은 창작 설정으로 분명히 구분한다.

- 역사적 사실은 출처를 표시하고 짧게 전달한다.
- 창작 설정을 역사적 사실처럼 표현하지 않는다.
- 인센스와 유등이 역사적으로 결합되어 있었다고 암시하지 않는다.
- 전쟁을 영웅적 폭력으로 소비하지 않는다. 적은 실루엣·횃불·그림자로 표현하고, 목표는 안부와 빛을 지키는 데 둔다.
- 제품 구매는 게임의 승패·진행도·확률·보상에 영향을 주지 않는다.

## 기술 방향

- 게임 엔진: Phaser 3
- 언어: TypeScript
- 개발·번들 도구: Vite
- 배포 형태: 모바일 브라우저용 정적 웹게임

Unity 에셋 스토어의 에셋은 타일·스프라이트·이펙트 등 원본 이미지 중심으로만 검토한다. Unity 전용 프리팹이나 게임 시스템에 의존하지 않는다.

## 온라인 마켓 연결

게임의 완료 화면에 남강유향 온라인 마켓과 관련 콘텐츠로 가는 선택적 링크를 둔다. 링크를 누르지 않아도 게임의 결말과 보상을 온전히 경험할 수 있어야 하며, 구매·할인·실물 경품·확률형 보상과 게임 규칙을 연결하지 않는다.

## 프로젝트 구조

깊은 하위 폴더를 만들지 않는다. 기획 문서는 루트에 두고, 에셋도 `assets/` 바로 아래에 파일명 규칙으로 정리한다. 실제 Phaser 소스만 `prototype/`에 둔다.

```text
GAME_남강유향/
├── README.md
├── game-design.md
├── world-bible.md
├── art-direction.md
├── asset-register.md
├── assets/
└── prototype/
```

| 경로 | 역할 | 현재 또는 다음 결정 |
|---|---|---|
| `README.md` | 프로젝트의 기준과 경로 안내 | 목적, 기술 선택, 핵심 루프, 범위 |
| `game-design.md` | 게임 규칙의 단일 기준 | 전장, 유등, 적, 3개 파도, 향 게이지, 승패 조건 |
| `world-bible.md` | 서사와 표현의 기준 | 안부·남강·등지기·침입군, 역사와 창작의 구분 |
| `art-direction.md` | 도트 아트와 UI 기준 | 해상도, 팔레트, 광역 점등, 최소 UI |
| `asset-register.md` | 외부 에셋 사용 기록 | 이름, 원본 링크, 라이선스, 사용 장면, 수정 여부 |
| `assets/` | 게임에서 쓰는 이미지·오디오 원본 | 배경, 타일, 유등, 적, 이펙트, UI를 파일명 접두사로 구분 |
| `prototype/` | Phaser + TypeScript 실제 소스 | 게임을 만들 때 Vite 프로젝트 생성 |

### `assets/` 파일 규칙

초기에는 하위 폴더를 만들지 않는다. 종류는 파일명으로 구분해 바로 찾는다.

| 접두사 | 용도 | 예시 |
|---|---|---|
| `bg_` | 전체 배경 | `bg_namgang_night.png` |
| `tile_` | 강·둔치·경로 타일 | `tile_river_01.png` |
| `lantern_` | 유등 스프라이트 | `lantern_silk_idle.png` |
| `enemy_` | 침입군 실루엣·배 | `enemy_boat_01.png` |
| `fx_` | 빛·물결·향·광역 점등 효과 | `fx_incense_burst.png` |
| `ui_` | 게이지·버튼·아이콘 | `ui_scent_gauge.png` |
| `sfx_` / `bgm_` | 효과음 / 배경음 | `sfx_lantern_light.wav` |

에셋이 충분히 많아져 이름만으로 찾기 어려울 때만 하위 폴더를 추가한다. 추가하거나 내려받은 모든 외부 에셋은 먼저 `asset-register.md`에 기록한다.

## 현재 범위 밖

- 유료 가챠, 확률형 할인, 구매 연계 실물 경품
- 제품 구매자만 가능한 전투력·진행도 보상
- 로그인, 계정, 저장 데이터, 복잡한 성장 시스템
- 검증 전의 장편 캠페인
- 역사적 사실로 보일 수 있는 인센스 효능·유래의 창작
