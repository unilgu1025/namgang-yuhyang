# 남강유향: 물결을 가르는 향등

## TL;DR

> **Summary**: 세로형 모바일 브라우저에서 한 손 스와이프로 향등 구슬을 조준·발사해 어둠 조각을 지우는 스테이지형 브릭 브레이커다. 남강의 물결, 유향의 궤적, 등불의 빛을 플레이 규칙과 시각 언어로 연결한다.
> **Deliverables**: 게임 핵심 규칙, 조작 명세, 3개 스테이지 밸런싱, 화면/UI 규칙, 아트·사운드·에셋 명세, 제작 백로그
> **Effort**: Medium
> **Parallel**: YES - 2 waves
> **Critical Path**: 조작·물리 프로토타입 → 스테이지·UI 구현 → 모바일 실기기 QA

## Context

### Original Request

스와이프 벽돌깨기 버전의 게임 기획서를 Markdown으로 작성한다.

### Interview Summary

별도 확인이 필요한 선택지는 모바일 짧은 세션에 가장 적합한 기본값으로 결정했다.

- 기존 `game-design.md`의 주사위 기반 유등 디펜스는 **레거시 기획**으로 보존한다. 이 문서는 후속 스와이프 브릭 브레이커 버전의 기준 문서다.
- 조작은 패들 이동형이 아니라 **스와이프 조준 후 일괄 발사** 방식이다. 손가락이 필드를 가려도 시작점과 조준선이 분리되어 한 손 사용성이 좋다.
- 한 판은 2~3분, 1개 스테이지는 10~14턴을 목표로 한다.
- `향`은 실물 제품의 효능과 무관한 창작 게임 자원이며, 연출과 규칙 모두에 사용한다.

### Metis Review (gaps addressed)

- 기존 장르와 충돌하지 않도록 새 문서로 분리하고, 같은 파일을 덮어쓰지 않는다.
- 모호했던 스와이프 의미, 승패, 공 수, 벽돌 체력, 모바일 안전 영역과 밸런스 초안을 명시한다.
- 결제·가챠·강제 광고·광고 부활·랭킹·로그인·계정 저장을 현 범위에서 제외한다.
- 남강과 유향 관련 표현은 창작 설정이며 역사적 사실 또는 제품 효능으로 주장하지 않는다.

## Work Objectives

### Core Objective

플레이어가 짧은 조준-발사-반사 연쇄를 통해 화면의 어둠을 비우고 마지막 향등에 빛을 되돌리는, 즉시 이해 가능하면서도 반복 플레이 가능한 브릭 브레이커를 만든다.

### Game Pillars

1. **한 번의 좋은 스와이프**: 조준선만 보아도 반사 경로와 기대 결과를 판단할 수 있다.
2. **연쇄의 만족감**: 다수의 구슬이 반사되며 향의 궤적을 남기고, 한 턴에 여러 조각을 깨면 강한 시청각 보상을 준다.
3. **남강유향의 분위기**: 실제 역사 재현이 아닌, 강물·빛·향을 모티프로 한 차분한 야간 판타지다.
4. **짧고 공정한 플레이**: 무작위 아이템, 결제, 광고 부활 없이 조준 실력과 명확한 스테이지 설계로 승부한다.

### Audience and Platform

| 항목 | 결정 |
|---|---|
| 대상 | 가볍게 2~3분 즐기는 모바일 웹 사용자 |
| 화면 | 세로 9:16 우선, 최소 360×640 CSS px |
| 엔진 | Phaser 3 + TypeScript + Vite |
| 입력 | 터치 스와이프 우선, 데스크톱에서는 마우스 드래그 |
| 저장 | 현 버전은 세션 내 진행만 유지, 로컬 저장 없음 |

### Core Loop

`스테이지 진입 → 조준선 드래그 → 향등 구슬 일괄 발사 → 반사·충돌로 어둠 조각 내구도 감소 → 모든 구슬 회수 → 하강/새 줄 생성 → 전부 제거 시 승리 또는 경계선 도달 시 실패`

1. 플레이어는 하단의 **향등 발사대**에서 스와이프를 시작한다.
2. 손가락을 뗀 순간, 모든 보유 구슬이 70ms 간격으로 같은 각도에 발사된다.
3. 구슬은 좌·우·상단 벽과 오브젝트에 반사되며, 오브젝트를 맞힐 때마다 내구도를 1 감소시킨다.
4. 바닥으로 돌아온 첫 구슬의 x좌표가 다음 턴 발사대 위치가 된다. 나머지 구슬은 같은 위치로 흡수된다.
5. 턴 종료 시 남은 조각은 1행 하강하고, 상단에 다음 행이 생성된다.
6. 조각이 하단 **등불 경계선**을 넘으면 패배한다. 모든 조각을 지우면 승리한다.

### Controls

| 상황 | 입력 | 결과 |
|---|---|---|
| 조준 시작 | 발사대 반경 72px 안에서 누르기 | 기준점과 반투명 조준선 표시 |
| 조준 | 위쪽으로 드래그 | 발사 각도 갱신, 상단·측면 첫 반사 1회까지 미리보기 |
| 발사 | 손가락 떼기 | 각도 고정, 전 구슬 순차 발사 |
| 취소 | 조준 중 발사대 아래로 드래그 | 조준선 숨김, 발사하지 않음 |
| 턴 진행 중 | 화면 탭 | 아무 동작 없음. 오발 방지 |

**조준 제한**: 수평 기준 ±12° 이내의 낮은 각도는 금지하고, 발사 벡터는 화면 위쪽을 향하는 18°~162°로 클램프한다. 조준선은 고대비 점선, 예상 충돌점은 작은 빛 점으로 보여 준다.

### Objects and Rules

| 오브젝트 | 기능 | 초기 수치 | 시각 모티프 |
|---|---|---:|---|
| 향등 구슬 | 한 충돌당 피해 1, 벽·오브젝트 반사 | 시작 1개, 최대 15개 | 금빛 심지와 청록 잔광 |
| 어둠 조각 | 기본 파괴 대상 | HP 1~18 | 먹빛 물결이 굳은 사각 조각 |
| 물결 매듭 | 파괴 불가, 반사 전용 | HP 없음 | 청자색 물결 고리 |
| 향주머니 | 닿으면 구슬 +1, 즉시 적용 | 스테이지당 1~3개 | 작은 비단 주머니와 향 연기 |
| 잔향 조각 | 연속 3개 파괴 시 생성, 닿으면 다음 턴 피해 +1 | 한 턴만 유지 | 연한 백색 연무 |
| 등불 경계선 | 조각이 닿으면 즉시 실패 | 화면 하단 18% 위 | 잔잔한 수면 위의 등불 띠 |

**콤보 규칙**: 같은 구슬이 1.2초 안에 조각 3개 이상을 연속 타격하면 잔향 조각을 하나 생성한다. 점수는 기록하지 않으며, 콤보는 화면 정화 연출과 플레이 보조 효과만 제공한다.

### Turn and Stage Structure

- 시작 구슬 수: 1개. 향주머니를 먹을 때마다 영구적으로 +1개.
- 기본 공 속도: 680px/s. 8개 이상일 때 760px/s로 증가해 턴 지연을 줄인다.
- 발사 간격: 70ms. 반환 구슬은 35ms 간격으로 발사대에 흡수한다.
- 한 스테이지 최대 턴: 14턴. 단, 14턴 전 모든 조각 제거 시 즉시 승리한다.
- 새 행: 턴 종료마다 1행 생성한다. 10턴부터는 2턴마다 한 행을 건너뛰어 회복 구간을 만든다.
- 한 행 최대 오브젝트: 7칸. 유효 플레이 영역은 7열 × 10행이다.

### Win / Loss / Reward

| 결과 | 조건 | 화면 결과 |
|---|---|---|
| 승리 | 필드의 파괴 대상이 0개 | 어둠이 수면에 녹고 중앙 향등이 점등, 다음 스테이지 버튼 |
| 실패 | 조각 하나가 등불 경계선에 닿음 | 등불이 잠시 흔들린 뒤 빛이 꺼짐, 즉시 재도전 버튼 |
| 중단 | 브라우저를 닫거나 새로고침 | 진행 저장 없음, 첫 스테이지로 복귀 |

보상은 다음 스테이지 해금과 엔딩 일러스트 조각뿐이다. 구매, 확률형 보상, 광고 시청 보상, 부활은 없다.

### Sample Stage Balance

| 스테이지 | 테마 | 시작 배치 | 행별 HP 범위 | 향주머니 | 목표 경험 |
|---|---|---|---:|---:|---|
| 1. 첫 물결 | 조준 학습 | HP 1 조각 5개, 매듭 1개 | 1~3 | 2 | 벽 반사와 회수 지점 이해 |
| 2. 흐르는 그림자 | 반사 퍼즐 | HP 2~7 조각 10개, 매듭 3개 | 2~7 | 2 | 긴 반사선과 안전한 각도 선택 |
| 3. 귀환의 등불 | 최종 연쇄 | HP 5~18 조각 16개, 매듭 5개 | 5~18 | 3 | 멀티볼·잔향 조각으로 대량 제거 |

**밸런싱 판정 기준**: 숙련되지 않은 플레이어가 스테이지 1을 3회 안에, 스테이지 2를 5회 안에 통과할 수 있어야 한다. 스테이지 3은 평균 8~12턴 내 승리, 마지막 3턴에 역전 기회가 한 번 이상 나오도록 배치한다.

### UX and Screen Specification

```
┌──────────────────────────────┐
│  [일시정지]  2-3: 흐르는 그림자 │  상단 안전 영역 48px
│                              │
│       어둠 조각 / 물결 매듭      │
│                              │
│        · · · 조준선 · · ·       │
│                              │
│ ─────── 등불 경계선 ───────── │
│     ○ ○ ○  향등 발사대          │  하단 조작 안전 영역 132px
└──────────────────────────────┘
```

- HUD는 스테이지명, 일시정지, 구슬 수만 표시한다. 점수·재화·상점 UI는 넣지 않는다.
- 텍스트는 16px 이상, 색만으로 상태를 구분하지 않는다. HP 숫자와 형태 변화(금 간 표면)를 함께 제공한다.
- 노치와 홈 인디케이터를 피해 상단 48px, 하단 34px의 안전 여백을 항상 확보한다.
- 색각 이상 사용자를 위해 조준선에는 점선, 잔향 조각에는 회전 아이콘, 향주머니에는 주머니 실루엣을 병행한다.

### Art Direction

| 레이어 | 방향 |
|---|---|
| 배경 | 남강을 직접 재현하지 않는 추상적 밤 수면. 남청·먹색 그라데이션과 느린 수면 반사 |
| 조각 | 완전한 벽돌 대신 모서리가 마모된 사각 수묵 조각. HP가 낮아질수록 균열과 빛샘 증가 |
| 구슬 | 중심은 따뜻한 호박색, 외곽은 청록빛. 잔상은 0.35초 내 사라지는 향 연무 |
| 이펙트 | 타격 시 작은 먹물 파편과 금빛 입자. 화면 전체 섬광은 피하고 국소 발광만 사용 |
| 모션 | 구슬은 탄성 있는 반사, 조각 파괴는 140ms 수축 후 연무 분해, 승리는 900ms 점등 |
| 금지 | 실존 문화재·복식·의례를 정확한 고증처럼 제시하는 표현, 상업 제품 효능을 암시하는 문구 |

### Audio and Haptics

- BGM: 70~80 BPM의 잔잔한 현악/물소리 기반 루프. 브라우저 자동재생 제한을 존중해 첫 발사 뒤 시작한다.
- SFX: 벽 반사(맑은 목탁), 조각 타격(낮은 유리음), 향주머니 획득(짧은 숨결), 승리(등불 심지 점화).
- 햅틱: 지원 기기에서만 조각 파괴 시 8ms, 승리 시 20ms. 시스템 설정 또는 게임 내 음향 버튼으로 함께 끌 수 있다.

### Must Have

- 스와이프 조준, 반사, 멀티볼 회수, 턴 단위 하강이 일관되게 작동한다.
- 시작·중간·최종 난이도를 보이는 3개 스테이지가 있다.
- 승리·실패가 즉시 이해 가능하며 재도전이 한 번의 탭으로 가능하다.
- 모든 브랜드/세계관 표현은 창작임을 문서에 명시한다.

### Must NOT Have

- 패들 조작, 자동 조준, 플레이 중 구슬 방향 변경
- 결제, 가챠, 확률형 보상, 광고 보상·광고 부활, 강제 광고
- 계정, 랭킹, 소셜 공유 강제, 장기 성장 트리, 상점
- 실물 향 제품의 성능·치유·효능을 연상시키는 문구
- 실존 역사나 지역 문화의 사실성을 단정하는 연출

## Verification Strategy

- **Test decision**: 프로토타입 구현 시 tests-after. 현재 산출물은 Markdown 문서이므로 문서 완결성 검토를 우선한다.
- **QA policy**: 각 구현 작업은 데스크톱 마우스와 모바일 터치에서 동일한 조준-발사-회수 결과를 확인한다.
- **Evidence**: 구현 시작 후 `.omo/evidence/task-{N}-swipe-brick-breaker.{ext}`에 스크린샷, 빌드 로그, 플레이 기록을 남긴다.
